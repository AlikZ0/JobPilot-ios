# JobPilot · iOS 17+

Локальный менеджер вакансий, откликов, интервью и follow-up. Приложение на SwiftUI + SwiftData без регистрации, сервера, веб-парсера, рекламы и сбора аналитики.

**Статус:** исходники, XcodeGen-конфигурация, GitHub Actions и unit-тесты подготовлены. Синтаксис Swift проверен Linux-компилятором (`swiftc -frontend -parse`). Полная сборка Xcode 16.4 и работа на реальном iPhone **пока не проверены**. CI скомпилирует проект после загрузки в GitHub, и если возникнет ошибка — ищите первую `error:` в логах.

## Готовые экраны

1. **Обзор:** активные отклики, ближайшие интервью, просроченные и сегодняшние задачи, воронка текущих статусов, добавление вакансии.
2. **Вакансии:** поиск, горизонтальные статусы, фильтры по должности/стеку/приоритету/удалённой работе из Армении, сортировка по ближайшему действию или дате обновления.
3. **Карточка вакансии:** компания, роль, зарплата, URL, требования, заметки, изменение статуса с историей, интервью, контакты и follow-up; полный каскадный ручной delete.
4. **Календарь:** системный графический календарь, события на выбранный день и ближайшие действия; переход к карточке для редактирования.
5. **Статистика:** период 7/30/90 дней или всё время, отклики, интервью, отказы, офферы, график текущих статусов.
6. **Настройки:** светлая/тёмная/системная тема, разрешение уведомлений, полный JSON backup, CSV только с вакансиями, импорт, полное удаление.

## Модели данных

SwiftData хранит пять независимых типов с UUID-связью `vacancyID`: `Vacancy`, `StageEvent`, `Contact`, `FollowUp`, `Interview`. Строковые raw values статуса/удалёнки сохраняют читаемый формат для JSON; статус определяется перечислением `VacancyStatus`.

Ручное удаление вакансии удаляет записи всех четырёх связанных типов; уведомления для follow-up и интервью отменяются. Операция сохраняется единой транзакцией через `ModelContext.save()`. Если сохранение завершилось ошибкой, UI показывает сообщение.

Нормализация URL ограничена HTTP(S), убирает фрагменты и известные tracking-параметры. При совпадении URL предлагается явно выбрать объединение или отдельную запись. Объединение пополняет только пустые поля и список технологий/заметок, не перезаписывает текущий статус и историю.

## Сборка через GitHub Actions без Mac

1. Создайте новый репозиторий GitHub, например `jobpilot-ios`.
2. Скопируйте **содержимое** этой папки в корень репозитория. Файл `.github/workflows/main.yml` должен лежать именно по этому пути (включите отображение скрытых файлов).
3. Откройте раздел **Actions → Build JobPilot for iPhone**. Push в `main` запускает workflow автоматически; также есть `Run workflow`.
4. Workflow выбирает Xcode 16.4 на `macos-15`, устанавливает XcodeGen, создаёт проект из `project.yml`, выполняет `xcodebuild archive` с отключённой подписью.
5. Только после успешного архива создаётся `Payload/JobPilot.app`, который упаковывается в `JobPilot-unsigned.ipa`.
6. В **Artifacts** скачайте архив `JobPilot-unsigned-IPA`; внутри находится `JobPilot-unsigned.ipa`.
7. **IPA неподписан.** Подпишите его через совместимый инструмент для установки на iPhone (например, SideStore или AltStore). Бесплатный Apple ID обычно имеет 7-дневный срок подписи и ограничение количества установленных приложений; условия могут отличаться.
8. Если установщик пожалуется на `bundle identifier`, задайте уникальное значение вместо `com.example.jobpilot` в `project.yml`, перезапустите сборку и подпись.

Секреты Apple ID не нужны и не добавлены в репозиторий. GitHub Actions не выполняет подпись на вашей учётной записи.

### Ручная сборка на Mac

```bash
brew install xcodegen
xcodegen generate --spec project.yml
xcodebuild -project JobPilot.xcodeproj -scheme JobPilot -configuration Release -destination 'generic/platform=iOS' -archivePath /tmp/JobPilot.xcarchive CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO SKIP_INSTALL=NO archive
```

### Запуск unit-тестов на Mac

```bash
xcodegen generate --spec project.yml
xcodebuild test -project JobPilot.xcodeproj -scheme JobPilot -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

Для тестов должен быть установлен соответствующий iOS Simulator runtime; измените имя устройства, если его нет. Тесты также можно запустить через **Actions → Run workflow → run_tests = true**; обычный push собирает IPA без запуска симулятора. Тесты проверяют валидацию/URL, CRUD и каскадное удаление, историю статусов, фильтры, JSON, CSV и абсолютные даты при разных часовых поясах.

## JSON/CSV и восстановление

- JSON резервирует все пять типов записей и сохраняет дату каждого события в ISO 8601 UTC. При импорте пропускаются записи с уже существующим ID или совпадающим нормализованным URL. Для импортируемых дубликатов связанные события тоже пропускаются. Существующие данные не затираются.
- CSV содержит **только вакансии**, в UTF-8 с кавычками и переносами строк по CSV; импорт поддерживает исключительно формат колонок JobPilot. Для восстановления истории/контактов/встреч используйте JSON.
- Удаление приложения iOS обычно удаляет его локальные данные. Для восстановления после переустановки **сначала экспортируйте JSON во «Файлы» вне папки приложения**, затем импортируйте его после новой установки.
- После импорта резервной копии события восстанавливаются, но уведомления не восстанавливаются автоматически — откройте и пересохраните нужные задачи и встречи.

## Уведомления

Приложение не запрашивает разрешение при первом запуске. В **Настройки → Разрешить уведомления** пользователь добровольно предоставляет доступ. Если доступ запрещён, сохранённые события остаются в базе и видны в календаре. В настройках можно проверить статус разрешения. Напоминание о follow-up планируется на заданное время, об интервью — за 30 минут (если эта дата ещё в будущем). При редактировании или удалении события запрос на уведомление обновляется или отменяется.

## Ограничения iOS и MVP

- Нет автоматической синхронизации между iPhone и iPad и входа в учётную запись. Все данные локальные. Для переноса используйте JSON.
- Нет парсинга вакансий с сайтов, Share Extension и App Groups. Быстрый ручной ввод URL уже есть в форме вакансии. Share Extension — вторая итерация.
- Нельзя отправить follow-up рекрутеру автоматически: приложение напоминает о нём, письмо пользователь отправляет самостоятельно.
- Не предусмотрены геолокация, фоновые обновления или скрытый мониторинг Gmail.
- Уведомление локальное: iOS может задержать или не показать его по системным правилам, в режиме фокусирования или при отключённом разрешении.
- CSV не является полноценным резервным форматом; для сохранения истории нужен JSON.
- Локализация: русский язык — основной; строки можно вынести в `Localizable.xcstrings` на следующем этапе. Сейчас полный перевод на другие языки **не сделан**.

## Проверка на настоящем iPhone

- [ ] Первый запуск: пустая библиотека, разрешения на уведомления не запрашиваются.
- [ ] Создать вакансию: компания, роль, URL; после перезапуска все поля сохранились.
- [ ] Пустая компания/роль, неверный URL, зарплата от больше чем до: ошибка с понятным текстом.
- [ ] Добавить вторую вакансию с той же ссылкой (включая UTM-метки): явный диалог про дубликат.
- [ ] Изменить статус «Сохранено» → «Откликнулся», подтвердить или отклонить follow-up; в истории есть запись.
- [ ] Добавить и отредактировать интервью, задачу и контакт. Переключить задачу в «Выполнено».
- [ ] Проверить календарь и сортировку в списке по ближайшему действию.
- [ ] Включить уведомления, создать follow-up на ближайшие минуты, проверить уведомление. При запрете разрешения задача остаётся в приложении.
- [ ] Проверить поиск, роль, стек, приоритет и фильтр remote from Armenia.
- [ ] Сменить темы Light → Dark → System, проверить клавиатуру, Dynamic Type, VoiceOver и Safe Area.
- [ ] Экспортировать JSON, импортировать его повторно: дубликаты пропущены. Импорт на новом чистом устройстве возвращает все пять типов.
- [ ] Экспортировать и импортировать CSV со строкой, содержащей кавычки и переносы.
- [ ] Удалить вакансию: история, задачи, контакты и интервью не остались в базе.
- [ ] Проверить длинные названия, 100+ вакансий, отсутствие сети и закрытие/повторное открытие приложения.

## Что осталось вне MVP

Safari Share Extension, автопарсинг вакансий, синхронизация через iCloud, вложения (CV/скриншоты), AI-оценка вакансий, почтовые интеграции, гибкая схема повторяющихся напоминаний и экспорт PDF-отчётов.

## Поддержка

При ошибках сборки откройте Actions → конкретный run → `Archive without signing` и найдите **первую строку `error:`**. Сохраняйте лог целиком: ошибка `exit code 65` только итоговый код, не причина.
